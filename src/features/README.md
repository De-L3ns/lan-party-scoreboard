# Feature modules

Feature modules are grouped by capability: `leaderboard/` renders standings and groups all players at each top-three rank on a shared podium step; `games/` provides player selection, team naming, active-game tiles, and rosters; `teams/` owns the wheel and draft controller; `admin/` provides organizer and result forms. `src/app.js` coordinates the guided screens, authentication, updates, and archive access. Setup and result pages preserve entered values across live refetches.

Use the shared client from `src/lib/supabase.js` for persistence and `src/domain/` for calculations. Rendering should not decide database permissions.

`games/mvp.js` provides the optional participant selector and the completed report's MVP highlight for all three formats. `result-saver.js` submits the nullable `mvp_player_id` atomically with points; corrections can change or clear it. The MVP carries no extra award and uses the game's saved participant identity. Migration `202611120001_game_mvp.sql` adds the participant constraint and authorized persistence. Before it is applied, ordinary result saves remain available and selected MVPs produce a migration-required error instead of being silently discarded.

Game result forms save directly, without a separate awards preview. `games/result-saver.js` captures the entry baseline and exact submitted allocation, waits for the existing revision-checked `save_result` acknowledgement, and emits one immutable transition per saved score event. `leaderboard/reveal.js` owns local reveal deduplication, replay, and cancellation; `reveal-view.js` owns the accessible modal, keyed player rows, measured layouts, and static point labels; `motion.js` always schedules the brief hold and frame-by-frame row movement. There is no motion toggle or stored motion preference for this popup. The application owns it independently of the departing result form. Realtime reads cannot rebase an open form or retarget an open reveal; sign-out, session changes, and disposal cancel it and clear its content. No new database migration is required.

The team picker is split into `controller.js` (reserved/committed picks, modes, autoplay, and observers), `view.js` (avatars and cancellable animations), `artwork.js` (bundled SVG artwork), `audio.js` (tab-local sound preference and playback), and `motion.js` (abortable animation/pause helpers). Both themes use the same server-controlled draw; public effects use published membership only.

Organizer-initiated picks explicitly enable full motion for their 4.2-second spin, lock-on pause, and effects. The controller clears that scoped override on completion/cancellation; passive viewers retain the existing reduced-motion behavior. The override covers both JavaScript timing and the picker-only CSS effects, without changing draw selection or global motion settings.

`knockout/` adds the third game format: `controller.js` reserves/commits opening reveals, records winners, requests confirmed undo, and reconciles live presentation events; `view.js` renders the connected bracket, saved player profiles, final awards report, and accessible versus dialog. It uses authoritative match state and stable published event IDs, never local draw randomness. Hidden/disposed views discard presentations and cannot continue publishing unseen pairings. `awards.js` groups final point inputs by finishing rank, lists the saved players in each group, and expands each rank value into per-player awards using the existing ledger pipeline and server-validated places. Unchanged live refreshes preserve rendered cards and portraits; bracket selections and command state update controls without rebuilding profiles.
